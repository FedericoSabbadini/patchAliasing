\section{Domain Description: Cyber-Physical PV Micro-Grid with Structural Aliasing Awareness}

The considered domain takes into account the energy generated by an asset infrastructure centered around a photovoltaic array (\texttt{pv:PhotovoltaicArray}), operating within a localized smart micro-grid ecosystem. This environment is dynamically monitored, analyzed, and managed by an autonomous AI control agent (\texttt{pv:ControlAgent}) that balances power flows and detects system failures. Uniquely, the domain bridges physical power generation with data science tokenization constraints, mapping how time-series windowing chunking strategies (\textbf{Chronos patch tokenization}) impact the data fidelity fed into machine learning models.

\subsection{Physical Assets and Grid Topology}
The physical core of the system is composed of four primary entities under the physical component (\texttt{pv:PhysicalComponent}) class, which are physically connected to (\texttt{pv:connectedTo}) one another to form the micro-grid's electrical topology:
\begin{itemize}
    \item The photovoltaic array serves as the primary generation source, defined by its physical size (\texttt{pv:panelCount}) and inverter nameplate capacity (\texttt{pv:nominalPowerW}).
    \item The array directly supplies power to (\texttt{pv:suppliesTo}) three downstream assets: the external national electricity grid (\texttt{pv:NationalGrid}) interface (an infinite bidirectional bus for energy exchange), local internal consumption loads (\texttt{pv:InternalLoad}) representing dynamic demand, and a local electrochemical storage unit (\texttt{pv:BatteryStorage}).
    \item Functionally, the battery storage unit actively buffers (\texttt{pv:buffers}) the photovoltaic array, absorbing excess generation or discharging power during deficits.
\end{itemize}

\subsection{Telemetry Streams and Tokenization Layer}
To evaluate system performance, data streams are continuously collected across two operational vectors:
\begin{itemize}
    \item The photovoltaic array measures (\texttt{pv:measures}) a continuous time-series signal (\texttt{pv:Signal}). This stream encapsulates instantaneous data properties such as photovoltaic power (\texttt{pv:pvPowerW}), global horizontal irradiance (\texttt{pv:horizontalIrradianceWm2}), and tilted surface irradiance (\texttt{pv:tiltedIrradianceWm2}), alongside frequency-domain metadata including the raw sampling rate (\texttt{pv:samplingFrequencyHz}), dominant periodic cycle frequency (\texttt{pv:fundamentalFrequencyHz}), wave amplitude (\texttt{pv:amplitudeW}), and phase offset relative to epoch (\texttt{pv:phaseRad}).
    \item Concurrently, the array is mapped via an environmental snapshot relationship (\texttt{pv:hasWeatherObservation}) to a weather observation log (\texttt{pv:WeatherObservation}), which tracks atmospheric variables like ambient air temperature (\texttt{pv:airTemperatureC}), wind speed (\texttt{pv:windSpeedMs}), and wind direction (\texttt{pv:windDirectionDeg}).
\end{itemize}
To prepare this continuous telemetry for deep learning inference, the raw signal passes through a processing layer that tokenizes (\texttt{pv:tokenizes}) it into a patched signal representation (\texttt{pv:PatchedSignal}). This sequence chunking strategy, tailored for foundation architectures like Chronos, is explicitly governed by architectural attributes: the token block size (\texttt{pv:patchSize}), window step stride (\texttt{pv:stride}), and calculated overlap ratio (\texttt{pv:overlapRatio}).

\subsection{Inferred Environmental Contexts and System Anomalies}
An execution reasoning engine dynamically updates the operational metadata of the system based on physical and mathematical constraints. The system extracts a baseline generation state (\texttt{pv:GenerationState}) derived from the tilted surface irradiance feature, classifying the current solar environment into one of four mutually exclusive subclasses: full peak production clear sky (\texttt{pv:ClearSkyState}), intermittent cloud cover (\texttt{pv:PartialCloudState}), dense cloud cover overcast (\texttt{pv:OvercastState}), or zero usable irradiance nighttime (\texttt{pv:NighttimeState}).

Simultaneously, the reasoner assesses system health by validating whether the photovoltaic array exhibits an anomaly (\texttt{pv:hasAnomaly}). It detects six distinct anomaly states (\texttt{pv:AnomalyState}):
\begin{itemize}
    \item \textbf{Clipping Anomaly (\texttt{pv:ClippingAnomaly}):} Occurs when solar power saturates at or above inverter nominal capacity during periods of high peak irradiance.
    \item \textbf{Inverter Trip Anomaly (\texttt{pv:InverterTripAnomaly}):} A hard breaker or component disconnection where output drops to zero despite significant solar resource availability.
    \item \textbf{Ramp Anomaly (\texttt{pv:RampAnomaly}):} Identified when the dynamic rate of power change (\texttt{pv:deltaPowerW}) between consecutive intervals exceeds safe structural ramp thresholds.
    \item \textbf{Soiling Anomaly (\texttt{pv:SoilingAnomaly}):} A persistent drop in normalized conversion efficiency, indicating panel surface contamination such as dust or soil accumulation.
    \item \textbf{Overheating Anomaly (\texttt{pv:OverheatingAnomaly}):} High ambient heat conditions inducing thermal derating, which depresses panel production efficiency under strong irradiance.
    \item \textbf{Malfunction Anomaly (\texttt{pv:MalfunctionAnomaly}):} A structural hardware fault where generation drops to a severely degraded, near-zero baseline without clear environmental causes.
\end{itemize}

\subsection{Machine Learning Vulnerabilities: Aliasing Events}
In parallel with physical faults, the semantic layer evaluates computational data-processing vulnerabilities. If tokenization window choices conflict with the signal's cyclical boundaries, the patched signal exhibits aliasing (\texttt{pv:exhibitsAliasing}), indicating an ongoing aliasing event (\texttt{pv:AliasingEvent}) that compromises downstream forecasting model precision:
\begin{itemize}
    \item A frequency blind spot (\texttt{pv:FrequencyBlindSpot}) is flagged when the continuous signal component matches an integer harmonic of the patch-induced frequency (\texttt{pv:patchInducedFrequencyHz}), rendering major cyclical patterns structurally invisible to the model (Hypotheses H1 and H1b).
    \item A phase aliasing effect (\texttt{pv:PhaseAliasingEffect}, Hypothesis H2) occurs when an active phase offset or spatial shift (\texttt{pv:phaseOffsetRad}) misaligns with token boundaries, degrading representation fidelity.
    \item An overlap distortion effect (\texttt{pv:OverlapEffect}, Hypothesis H3) reveals configuration setups where a low overlap ratio indicates suboptimal stride lengths, generating context sequence block redundancy.
\end{itemize}

\subsection{Closed-Loop Autonomous Action}
To restore grid equilibrium and preserve physical integrity, the photovoltaic array triggers actions (\texttt{pv:triggersAction}) belonging to the agent action (\texttt{pv:AgentAction}) class hierarchy. The autonomous control agent manages the closed-loop optimization loop and performs (\texttt{pv:performs}) four specialized mitigation interventions:
\begin{itemize}
    \item It coordinates a battery dispatch intervention (\texttt{pv:BatteryDispatchAction}) to buffer grid fluctuations under volatile weather or to substitute lost generation during unexpected inverter breaker trips.
    \item It deploys a generation curtailment action (\texttt{pv:CurtailGenerationAction}) to throttle active power spikes during inverter clipping or critical panel overheating states.
    \item It initiates demand side load adjustment changes (\texttt{pv:LoadAdjustmentAction}) to shift internal consumer consumption steps during low overcast or zero production nighttime states.
    \item It issues a rapid warning alert (\texttt{pv:RampAlertAction}) to stability systems the instant an active ramp rate anomaly is detected.
\end{itemize}
