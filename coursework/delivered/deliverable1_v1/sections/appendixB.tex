Since variations in the values of stride and patch size require a new training of the model we have selected a restricted set of parameters for which the model is re-trained.

To obtain a comprehensive understanding of the impact of stride and patch size on the presence of structural aliasing, we have selected a set of reduced stride and patch size values, and a set of increased stride and patch size values, to evaluate the possibility of mitigating the phenomenon.

We also considered the case of fixed patch size to default value 16 and variable stride to evaluate the impact of stride on the presence of structural aliasing.

Since the training procedure is computationally expensive, we have selected a limited number of training examples and so we have decided to re-train the model also for the default values of patch and stride, with the aim of having a baseline for comparison with the other configurations. The process is undertaken using the pipeline and data described in \autoref{sec:appendixC}, with stride and patch size parameters systematically varied according to the values reported in \autoref{tab:patchStride}.
